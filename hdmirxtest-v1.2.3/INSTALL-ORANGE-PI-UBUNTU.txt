HDMIRXTEST V1.2.3 — COMPLETE CLEAN INSTALL (UBUNTU 24.04)
===========================================================

This installation uses the exact project path shown below. Run commands on the
Orange Pi as the normal `visionseek` user unless a command invokes sudo.

1. STOP THE OLD SERVICE AND REPLACE THE CHECKOUT
------------------------------------------------

    cd /
    sudo systemctl stop hdmirxtest-passthrough.service 2>/dev/null || true
    sudo systemctl stop hdmirxtest-edid.service 2>/dev/null || true
    mkdir -p /home/visionseek/src
    rm -rf -- /home/visionseek/src/hdmirxtest
    cd /home/visionseek/src
    git clone https://github.com/N0tiK44/hdmirxtest.git
    cd /home/visionseek/src/hdmirxtest
    cat VERSION

The version must report:

    1.2.3-persistent-systemd-fast-relock

2. INSTALL DEPENDENCIES AND BUILD
---------------------------------

    bash scripts/install-deps.sh
    make check
    make -j"$(nproc)"

3. ONE-TIME SAFE EDID SETUP
---------------------------

Physical wiring before this command:

    Orange Pi HDMI-TX -> target monitor: connected
    Windows/GPU HDMI  -> Orange Pi HDMI-RX: physically unplugged

Then run:

    bash scripts/pi-cycle.sh setup

Do not reconnect HDMI-RX until setup prints both:

    HDMI-RX exact read-back: verified
    systemd EDID loader and persistent passthrough installed/enabled

4. CONNECT WINDOWS AND START PERMANENT VIDEO
--------------------------------------------

Reconnect Windows/GPU HDMI to HDMI-RX. Keep Windows in Extend mode, wait for
Windows to enumerate the display, then run:

    bash scripts/pi-cycle.sh service-start

Inspect status and the live log with:

    bash scripts/pi-cycle.sh service-status
    sudo journalctl -fu hdmirxtest-passthrough.service

The service survives SSH logout and starts automatically on later Pi boots.

5. OPTIONAL FOREGROUND OR TIMED TESTS
-------------------------------------

Stop the persistent service and run in the foreground continuously:

    bash scripts/pi-cycle.sh service-stop
    bash scripts/pi-cycle.sh 240

Press Ctrl-C to stop. For a 120-second result archive instead:

    DURATION=120 bash scripts/pi-cycle.sh 240

The timed result is:

    /home/visionseek/hdmirxtest-240-latest.tar.gz

6. REBOOT VERIFICATION
----------------------

    sudo reboot

After reconnecting over SSH:

    cd /home/visionseek/src/hdmirxtest
    bash scripts/pi-cycle.sh service-status

7. MONITOR REPLACEMENT
----------------------

Stop video, physically unplug HDMI-RX, connect the new HDMI-TX monitor, and
repeat setup:

    bash scripts/pi-cycle.sh service-stop
    bash scripts/pi-cycle.sh setup

Reconnect HDMI-RX and run `bash scripts/pi-cycle.sh service-start`.

Never change the hosted EDID underneath an active Windows HDMI connection.
