the Orange Pi before building.

Hardware validation still required on the Orange Pi:

2. Run `bash scripts/pi-cycle.sh setup`.
3. Confirm exact EDID write/read-back verification passes.
4. Reconnect HDMI-RX and let Windows enumerate the cloned monitor identity.
5. Run `bash scripts/pi-cycle.sh 240` and verify sustained native BGR3/RGB888
