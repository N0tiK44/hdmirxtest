# V1.2.2 — downstream identity clone and tamper-evident state

- Normal setup preserves the real HDMI-TX monitor manufacturer ID, product
  code, numeric serial, monitor name and textual serial.
- The generated source-facing EDID remains a filtered capability intersection:
  maximum 1920x1080, 240 Hz and 600 MHz pixel clock; RGB 8-bit SDR only.
- DSC, FRL, HDR, VRR/FreeSync, YCbCr, deep colour, audio and unknown
  timing-bearing extensions are not advertised because the present video-only
  bridge has not proven those features end-to-end.
- Setup records raw-sink and generated-bridge SHA-256 values and identities in
  `/var/lib/hdmirxtest/bridge-manifest.json`.
- The live path verifies an exact EDID read-back and detects a replaced
  HDMI-TX monitor before video starts.
- A changed monitor is staged automatically. An active HDMI-RX source is never
  hot-rewritten; one controlled disconnect/setup/reconnect cycle is required.
- The `RKP / RK-BRIDGE` identity is retained only for the emergency 1080p60
  recovery profile, not normal impersonation mode.
