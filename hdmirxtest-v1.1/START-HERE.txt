HDMIRXTEST V1.1
================

FIRST SETUP

1. Connect the target monitor to Orange Pi HDMI-TX.
2. Physically unplug Windows from Orange Pi HDMI-RX.
3. Run:

       bash setup.sh

4. Reconnect Windows to HDMI-RX after setup succeeds.

NORMAL USE

       bash PiCycle.sh

Press Ctrl+C to stop video and return to the terminal.

FULLSCREEN-EXCLUSIVE GAMES

PiCycle stays alive when a game temporarily removes the HDMI signal and
automatically relocks when the new resolution/refresh timing appears. A short
black screen during HDMI retraining is normal. If a game requests an
unadvertised mode or repeatedly fails to relock, use borderless-windowed mode
and collect: bash PiCycle.sh debug

MODE POLICY

Setup reads the connected HDMI-TX display and advertises only its explicit
timings that also fit the bridge limits: 3840x2160 maximum geometry, 240 Hz
maximum refresh and 600 MHz maximum pixel clock, using RGB 8-bit SDR.

Examples that may coexist when the display advertises them include 4K60,
1440p modes and 1080p240. The HDMI source chooses from the resulting list.

The bridge does not scale video. It also does not forward HDMI audio or act as
an HDCP repeater. Protected content may remain blank even after timing lock.

NEW MONITOR

1. Press Ctrl+C.
2. Unplug Windows from HDMI-RX.
3. Connect the replacement monitor to HDMI-TX.
4. Run: bash PiCycle.sh setup
5. Reconnect Windows.
6. Run: bash PiCycle.sh

DEBUG SNAPSHOT

       bash PiCycle.sh debug
