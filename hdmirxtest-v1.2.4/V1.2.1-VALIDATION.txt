Hardware checks required on Orange Pi 5 Plus:

1. Keep Windows physically unplugged from HDMI-RX.
2. Connect the target monitor to HDMI-TX.
3. Run `bash scripts/pi-cycle.sh setup`.
4. Confirm exact read-back and OpenRC loader installation.
5. Connect Windows only after setup succeeds.
6. Confirm Windows lists no mode above 1920x1080 or 240 Hz.
7. Run `bash scripts/pi-cycle.sh 240` and return the result archive.

The complete binary must still be built against the Orange Pi's libdrm/kernel
headers; this container does not provide the Rockchip hardware or libdrm-dev.
