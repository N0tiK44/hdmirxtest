HDMIRXTEST V1.2.4 — CLEAN ORANGE PI INSTALL
============================================

Run these commands as the normal visionseek user.

1. REMOVE THE OLD CHECKOUT AND CLONE GITHUB
--------------------------------------------

       cd /
       sudo systemctl disable --now hdmirxtest-passthrough.service 2>/dev/null || true
       mkdir -p /home/visionseek/src
       rm -rf -- /home/visionseek/src/hdmirxtest
       cd /home/visionseek/src
       git clone https://github.com/N0tiK44/hdmirxtest.git
       cd /home/visionseek/src/hdmirxtest/hdmirxtest-v1.2.4
       cat VERSION

It must print:

       1.2.4-foreground-ctrl-c-simple-install

2. INSTALL EVERYTHING WITH ONE COMMAND
---------------------------------------

Before running setup:

       HDMI-TX -> target monitor: connected
       Windows -> HDMI-RX:       physically unplugged

Then run:

       bash setup.sh

3. START AND STOP VIDEO
-----------------------

Reconnect Windows to HDMI-RX and wait for Windows to detect the display.

Start video:

       bash PiCycle.sh

Stop video and return to the terminal:

       Ctrl+C

That is the complete normal workflow. Do not use service-start, service-status,
or service-stop; V1.2.4 deliberately runs video in the foreground only.

4. OPTIONAL DIAGNOSTICS
-----------------------

       bash PiCycle.sh debug

The latest archive is written to:

       /home/visionseek/hdmirxtest-debug-latest.tar.gz
