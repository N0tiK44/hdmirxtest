HDMIRXTEST V1.1.3 — SIMPLE PI-ONLY 240-HZ TEST
================================================

IMPORTANT
---------
Use Windows EXTEND THESE DISPLAYS. Do not use Duplicate.
Run every project command below on the Orange Pi.


1. INSTALL ONCE
===============

    mkdir -p ~/src
    cd ~/src
    git clone https://github.com/N0tiK44/hdmirxtest.git
    cd hdmirxtest
    bash scripts/install-deps.sh


2. LOAD THE 240-HZ EDID
=======================

    cd ~/src/hdmirxtest
    bash scripts/pi-cycle.sh prepare240

Wait for exact EDID read-back success. Physically unplug/replug the HDMI cable
from the Windows CPU/iGPU to the Orange Pi. In the ordinary Windows Display
Settings GUI, keep extended mode and select RK-1080P240 at 1920x1080 240 Hz.
Keep 8-bit SDR, HDR off, and VRR off for this test.


3. RUN THE FIXED 240-HZ PATH
============================

    cd ~/src/hdmirxtest
    bash scripts/pi-cycle.sh 240

V1.1.3 automatically accepts either native source format:

    RGB888 source  -> V4L2 BGR3 -> DRM RGB888/RG24
    YUV444 source  -> V4L2 NV24 -> DRM NV24

Both are direct DMA-BUF zero-copy paths. There is no GStreamer, CPU colour
conversion, framebuffer copy, or deliberate extra frame queue.

Result:

    ~/hdmirxtest-240-latest.tar.gz


4. EMERGENCY RESTORE
====================

    cd ~/src/hdmirxtest
    bash scripts/pi-cycle.sh restoreedid

Then physically reconnect the Windows-source HDMI cable.


5. OPTIONAL BASELINE OR DEBUG
=============================

    bash scripts/pi-cycle.sh baseline
    bash scripts/pi-cycle.sh debug

Results:

    ~/hdmirxtest-baseline-latest.tar.gz
    ~/hdmirxtest-debug-latest.tar.gz
