HDMIRXTEST V1.1.3 — START HERE
================================

All project commands run on the Orange Pi.
Windows only selects the detected display mode in the normal Display Settings GUI.

Repository:
https://github.com/N0tiK44/hdmirxtest

After V1.1.3 is uploaded to main, run on the Orange Pi:

    cd ~/src/hdmirxtest
    bash scripts/pi-cycle.sh prepare240

Physically reconnect the Windows-source HDMI cable, use extended-display mode,
and select 1920x1080 at 240 Hz. Then run on the Orange Pi:

    bash scripts/pi-cycle.sh 240

Result:

    ~/hdmirxtest-240-latest.tar.gz

Emergency EDID rollback:

    bash scripts/pi-cycle.sh restoreedid

V1.1.3 accepts the actual 240-Hz RGB input as native V4L2 BGR3 and scans it
out as DRM RGB888/RG24 without a conversion, CPU copy, or extra queue.
