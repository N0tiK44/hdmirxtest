HDMIRXTEST — START HERE
=======================

Repository:
https://github.com/N0tiK44/hdmirxtest

For the simplest instructions, open:

    TUTORIAL.txt

The normal Orange Pi command is:

    cd ~/src/hdmirxtest && bash scripts/pi-cycle.sh baseline

Debug-only command:

    cd ~/src/hdmirxtest && bash scripts/pi-cycle.sh debug

The result archive is:

    ~/hdmirxtest-latest.tar.gz

Windows 11 PowerShell command to copy it:

    scp visionseek@192.168.20.35:~/hdmirxtest-latest.tar.gz "$env:USERPROFILE\Downloads\hdmirxtest-latest.tar.gz"

For the easiest Windows-controlled workflow, clone the repository once on the
Windows host and double-click:

    RUN-BASELINE.cmd

For debug only:

    RUN-DEBUG.cmd

For result copy only:

    FETCH-RESULTS.cmd

For the experimental 1080p240 workflow, after the baseline passes:

    RUN-240-WIZARD.cmd

See TUTORIAL.txt for the full step-by-step instructions.
